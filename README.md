# HR Management System

A simple, ready-to-use HR management system for personal use.

## Features
1. **Employee Records** - Manage employee information
2. **Leave Management** - Track and approve leave requests
3. **Visa Expense** - Monitor visa-related expenses

## How to Use

### Option 1: Use Online (Simplest)
1. Go to the `index.html` file in this repository
2. Click the raw button or download it
3. Open it in any web browser
4. Start using immediately!

### Option 2: Download and Run
1. Download all files to your computer
2. Open `index.html` in any web browser
3. Done! No installation needed.
